# 📋 How to Use These Templates in Notion

## Quick Setup

1. **Create a new Notion page** for each report type
2. **Copy the markdown sections** above and paste into Notion
3. **Tables will auto-convert** to Notion tables
4. **Callouts (> blocks)** will become Notion callout blocks
5. **Add a database** for the metrics that need to be dynamic

## Making It Dynamic

For live data, create Notion databases with these properties:

### Sales Effectiveness Database
- Company (Title)
- Total Revenue (Number, currency)
- Orders (Number)
- AOV (Formula: Revenue / Orders)
- Activation Rate (Number, percent)
- Self-Service % (Number, percent)
- Last Updated (Date)

### Instance Health Database
- System (Title)
- Status (Select: Healthy, Warning, Error)
- Last Sync (Date)
- Success Rate (Number, percent)
- Manual Updates (Number)
- Last Updated (Date)

### Rep Performance Database
- Rep Name (Title)
- MTD Revenue (Number, currency)
- MTD Orders (Number)
- AOV (Formula)
- SmartPicks Usage (Number, percent)
- Feature Score (Rollup)
- Last Updated (Date)

## Embedding in Notion

Use linked databases with filtered views to show:
- **This Month** vs **Last Month** comparisons
- **By Territory** or **By Rep** filters
- **Status = Warning or Error** for alerts

# 🎨 Notion Formatting Tips

| Element | Markdown | Notion Result |
|---------|----------|---------------|
| Callout | `> Text` | Callout block |
| Warning | `> ⚠️ Text` | Yellow callout |
| Tip | `> 💡 Text` | Blue callout |
| Success | `> ✅ Text` | Green callout |
| Error | `> 🔴 Text` | Red callout |
| Table | Markdown table | Notion table |
