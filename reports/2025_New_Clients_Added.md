## Query Used

```sql
SELECT DISTINCT
  d.deal_id,
  d.properties_dealname as deal_name,
  c.properties_name as company_name,
  c.properties_domain as company_domain,
  d.properties_amount as amount,
  FORMAT_TIMESTAMP('%Y-%m-%d', d.properties_closedate) as close_date,
  FORMAT_TIMESTAMP('%Y-%m-%d', d.properties_createdate) as create_date,
  DATE_DIFF(DATE(d.properties_closedate), DATE(d.properties_createdate), DAY) as days_to_close,
  CONCAT(o.first_name, ' ', o.last_name) as owner_name
FROM hubspot__deal d
LEFT JOIN hubspot__deal_company dc ON d.deal_id = dc.deal_id
LEFT JOIN hubspot__company c ON dc.company_id = c.company_id
LEFT JOIN hubspot__owner o ON CAST(d.properties_hubspot_owner_id AS STRING) = o.owner_id
WHERE d.properties_hs_is_closed_won = true
  AND d.properties_dealtype = 'newbusiness'
  AND d.properties_closedate >= '2025-01-01'
  AND d.properties_closedate < '2026-01-01'
ORDER BY close_date DESC
```

---

*Report shows closed-won new business deals only. Does not include upsells, renewals, or existing client expansions.*
