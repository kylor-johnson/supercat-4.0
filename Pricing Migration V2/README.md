# Pricing Migration V2

SuperCat 2026 pricing migration — production HTML draft generator.

## Quick start

```bash
cd "Pricing Migration V2"
python3 build.py              # builds all 55 June cohort drafts
python3 build.py --ord lpf    # builds one account (ord_id = lpf)
python3 build.py --segment Core  # builds one segment
```

Open any file in `drafts/` in a browser to review. Send the HTML directly or copy into email.

## Updating a draft after review

Edit `build.py` lookup tables to change:
- **Driver explanation prose** → `DRIVER_EXPLANATIONS` dict
- **Tier features** → `TIER_FEATURES_HTML` dict
- **Next-steps copy** → `next_steps_copy()` function

Re-run `build.py` to regenerate. The CSVs are the authoritative data source — do not hand-edit draft HTML files.
