## New Option Type architecture (8 single types)
Set these in **Tools → Company Settings → Option Types** in this exact order
(the number = OptionSet column = on-iPad section heading / display order):

| # | Option Type (section heading) | Group prefix | # groups |
|---|---|---|---|
| 1 | Finish *(Required)* | FIN | 2 |
| 2 | Wall Mount | WM | 27 |
| 3 | Wall Accessories | WA | 65 |
| 4 | Ceiling Mount | CM | 122 |
| 5 | Post & Pier Mount | PP | 40 |
| 6 | Decorative | DEC | 48 |
| 7 | Electric | ELE | 5 |
| 8 | Gas | GAS | 7 |

8 types = the eCat default cap, so **no expansion request needed**. This directly resolves the
"items filed under the wrong section heading" feedback: each option now lives in exactly one
type, and the headings come from these Option Type labels (not from group names).
