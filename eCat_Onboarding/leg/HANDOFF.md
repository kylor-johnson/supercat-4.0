## Rules in effect
- **Taxonomy = Auto-Create** (the Collection/Category strings ARE the iPad
  labels; one collection + one category per item). TradeName = `Legrand`.
  Validated against legrand.us: adorne + radiant are the two Collections; the 40
  categories map to the site's functional families.
- **No product options.** `Add Option 1..10` are 100% empty and each finish is
  its own orderable SKU. Finish variants are modeled as **RelatedItems**, never
  OptionSets. Do not build options.csv / OptionSet columns.
- **RelatedItems**: SKUs that differ only by finish are grouped (product name
  with the Finish token stripped); every member lists the full family incl.
  itself. Currently **872 SKUs across 173 families**. Built-in reserved field —
  no Admin registration needed.
- **Custom fields MUST be registered** in Admin → Products → Custom Fields with a
  Label + "Send to iPad" or the column is ignored on import. See
  `custom-fields-setup.md` for the exact list.
- **Finish** is a multi-select filter. `FINISH_FIXES` merges only unambiguous
  typos (`Grahite`→`Graphite`, `Tri Color`/`Tri-color`→`Tri-Color`). Do NOT
  auto-merge `Gloss White` vs `Gloss White-on-White` (confirmed DISTINCT on
  legrand.us), nor the Mirror / Brushed-Stainless groups — flagged for client.
- **Null handling**: treat `""`, `#N/A`, `N/A` as blank everywhere; treat `0` as
  blank for measurements/prices.
