## Format Selection

| Account Profile | Format | Template File |
|---|---|---|
| Price normalization, delta ≤10% | **Format A** | `format_a_normalization_near_flat.md` |
| Price normalization, delta >10% | **Format B** | `format_b_normalization_significant_delta.md` |
| Expansion: T1→T2 upgrade opportunity | **Format C** (subtype A) | `format_c_expansion_upgrade.md` |
| Expansion: T2→T3 upgrade opportunity | **Format C** (subtype B) | `format_c_expansion_upgrade.md` |
| Internal CEO/CS prep (paired with any brief) | **Prep Sheet** | `internal_ceo_cs_prep_sheet.md` |

---

## Delta Thresholds

| Delta % | Format | Notes |
|---|---|---|
| 0–10% | Format A | Near-flat. Simple notice, no persuasion needed. |
| 10–25% | Format B | Significant. Two-part: CEO letter + math appendix. |
| >25% | Format B | High-risk. CEO calls before sending. Prep sheet required. |

---

## Sequencing Rules

1. **Normalization brief (Format A or B) is always first.** Never send an expansion brief (Format C) concurrently.
2. **Expansion requires a positive migration signal** — explicit acknowledgment, engagement question about the next tier, or no objection after 14 confirmed delivery days. Silence does not clear the gate.
3. **Expansion is blocked if:** account objected to migration brief, account is Watch band + delta >20%, account is At Risk or Critical, or CSM has an open support issue.
