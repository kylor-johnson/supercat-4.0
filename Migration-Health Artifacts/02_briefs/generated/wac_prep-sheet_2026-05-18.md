## Migration Driver: What You're Correcting

**multi_org_retirement + user_rate_change**

WAC/Modern Forms Lighting was enrolled in SuperCat's multi-organization pricing program as a rollup child of WAC Group. The program applied a 10% cross-entity discount to both the platform base and the user rate. The platform base was discounted from the $725 book rate to $652.50 (platform base received ~10% discount; final rate is $652.50). The user rate was discounted from a $20/user contracted rate to $18/user (10% multi-org discount applied to the contracted rate). Both discounts are being retired.

At migration:
- Platform base: $652.50 → $749.00 (+$96.50/month)
- User rate: $18.00/user flat → graduated standard ($25/$22/$20/$18)
- Included users: 25 (multi-org program) → 10 (T1 standard)
- Modeled user charge at 97 trailing avg: $1,098.00 → $1,746.00 (+$648.00/month)
- **Net delta: +$744.50/month (+42.5%)**

The large delta is driven primarily by the user rate change (+$648) rather than the platform base correction (+$96.50). WAC has 87 excess users above the standard T1 included base of 10 — which means any user rate increase or included-base adjustment hits them harder than a typical T1 account.
