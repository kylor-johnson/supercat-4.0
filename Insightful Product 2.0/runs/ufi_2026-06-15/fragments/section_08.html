Recurring Import Warnings

Product file imports consistently generate four non-blocking warnings for unrecognized price column headers — Price_BBD, Price_BBW, Price_BLD, and Price_BLW — appearing in each daily product import as of June 2026. These warnings do not prevent successful processing, but indicate price fields in the source file that are not mapped to configured price levels in the platform. Resolving the column mapping or removing unused columns would produce clean import logs.

What this tells you: Your import pipeline is healthy and operates on a consistent daily schedule with no processing failures. The four recurring price column warnings are non-blocking but worth addressing — either map those price codes to configured price levels or remove them from the source file for cleaner import logs.
