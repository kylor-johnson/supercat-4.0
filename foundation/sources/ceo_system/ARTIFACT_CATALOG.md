## Autonomous execution

The orchestrator (`skills/ceo_system/orchestrator/`) runs all 16 scheduled
prompt types (17 runs/week — `sales_AE_week_ahead` runs once per rep)
autonomously via the Anthropic API. See `orchestrator/config.yaml`
for model selection (Opus 4.6 for VoM + Digest + agent_research, Sonnet 4.6
for all others), retry policy, and agent loop guardrails. For how context is
composed into each report, see [`ARCHITECTURE.md`](ARCHITECTURE.md).
