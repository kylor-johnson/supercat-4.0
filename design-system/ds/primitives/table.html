Data table .kdt

A framework-agnostic data table that reads like editorial typography. Hairlines, tabular numerals, restraint. Default density sits at 52 px — premium and iPad-friendly. Hover and selected both lift the row a half-step toward paper. Selection is signaled by the checked chip in the first column. No row ever turns pink, no crimson chrome anywhere.

Orders table — the new shape

Direct replacement for the current Orders screen. Order # is body text, not a link — that's an in-cell affordance, not a brand moment. Customer names hold a single line; addresses fall back to a whispered em-dash when empty (no orphan commas). Timestamps are tabular mono so the column scans without jitter.

Status pills

Built into table.css so the primitive ships zero-dependency. When the standalone Tag primitive .kt-* lands, these will alias to it — same markup, no migration in pages.

StatusToken mappingUse when

Selection & bulk actions

09

Loading — skeleton rows

Set aria-busy="true" on the <tbody> and render N .kdt-skel rows. Bar widths vary per column via style="--w: 60%" so the skeleton reads as plausible content rather than a uniform stripe.

Responsive collapse — stack to cards

Below 640 px the same markup re-flows into per-row cards with label-value pairs. Add .kdt-stack to the wrapper and data-label to each <td>. Resize this window narrower than 640 px to see it. iPad-split-view friendly.
