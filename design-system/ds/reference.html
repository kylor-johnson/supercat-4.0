01.6

Logo

One wordmark, one icon mark — eight authorised placements. The double-wave brand glyph is gold by default; everything else maps to the surface it sits on. Never render the brand as text + icon, never recolor the mark outside this matrix.

supercat-mark.svg

Brand mark · 4 placements 41 × 28
Gold · on cream
Gold · on dark
Cream · on crimson
Ink · on gold
Default placements — letters take currentColor (ink on cream, cream on dark). The gold double-wave on top is the brand spike — never substitute another color in the default forms.
Monochrome — both letters AND mark collapse to one ink. Use when color is unavailable (print, fax, single-color embroidery) or when the gold would compete with a content image behind it.
On crimson — cream mark only. Used on primary CTA pills, avatars, and the active sidebar accent (when crimson is the surface, not an accent).
On gold — ink mark only. Brand-on-brand surfaces (gold welcome panels, gala collateral). Keeps contrast without two competing brand colors.
Don't — recolor the gold spike, swap the mark for a text "S", outline the strokes, drop on a busy photo, or build the brand as [icon] + "Supercat" text. The vectors are authoritative.

02.12

Marketing nav · .vn

The universal two-pill marketing nav. One source of truth — every marketing-web surface uses the same <sc-marketing-nav> snippet; change the markup once in nav/marketing-nav.js and every page updates. Left pill: logo wordmark + System / App / Docs hover-mega menus. Right pill: theme toggle + Open App CTA. Mobile: collapses to burger + accordion.

CSS JS · snippet
Snippet · paste anywhere<sc-marketing-nav>
<sc-marketing-nav current="reference"></sc-marketing-nav>

Optional attributes: current (portal · reference · dashboard · orders · …), cta-href, cta-label. The nav script also auto-injects a hidden <symbol id="sc-wordmark">, so any page can drop <svg><use href="#sc-wordmark"/></svg> without re-inlining the paths.

02.13

Footer · .kfoot

§ 05

For developers

Three links, one stylesheet. The system is class-only — drop the CSS into any framework and start composing. No build step. No JS for basic states.

Quick start

The shortest correct page. Tokens first, then any primitive you need. Same code in React, Vue, Svelte, vanilla.
